# XP Ultimate Simulator - Ek Özellikler

Bu sürümde eklenen yeni özellikler:

- Start menüsünden **Ayarları Dışa Aktar / İçe Aktar**
- JSON tabanlı state import/export (`xp-state.json`)
- **Komut Paleti** (`Ctrl+K`):
  - `open <uygulama>`
  - `tile`
  - `cascade`
  - `lock`
  - `desktop`

## Kullanım

1. Start > Ayarları Dışa Aktar ile mevcut düzeni ve renkleri JSON olarak indir.
2. Start > Ayarları İçe Aktar ile JSON dosyasını geri yükle.
3. `Ctrl+K` ile komut paletini açıp hızlı komutlar çalıştır.
