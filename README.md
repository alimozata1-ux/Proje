# Team Fortress 2 OS Simülatör

Basit bir terminal tabanlı **Team Fortress 2 temalı işletim sistemi simülatörü**.

## Çalıştırma

```bash
python3 tf2_os_simulator.py
```

## Komutlar

- `status` → Sistem durumunu gösterir.
- `deploy` → Bir TF2 sınıf modülü çalıştırır.
- `defend` → Gelen saldırı dalgasını savunur.
- `tick` → Arka plan döngüsünü ilerletir.
- `help` → Kısa yardım mesajı.
- `exit` → Simülatörden çıkış.

## Not

Bu proje eğlence amaçlıdır ve resmi Valve/TF2 ürünü değildir.
